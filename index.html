NVTalk

Audio-Driven Talking Head Generation

Given a single portrait image and an audio clip, NVTalk synthesizes a realistic, lip-synced talking-head video with controllable facial expressions and gaze direction — inspired by VASA-1, LivePortrait, and Ditto.

⭐ GitHub Demo Paper

Abstract

NVTalk is an audio-driven talking-head framework that generates photo-realistic, temporally coherent facial animations from a single still image and an arbitrary speech audio. Beyond lip synchronization, NVTalk supports controllable facial expressions by emotions and gaze direction, enabling expressive and natural-looking talking-head synthesis.

A key distinction from prior work such as Ditto is NVTalk's 250 ms pose prediction window, which significantly reduces latency and enables true real-time streaming inference — making it suitable for live interactive applications. NVTalk introduces a unified pipeline that achieves high visual fidelity with minimal end-to-end delay.

Current project status: The model is under active development. Ongoing work includes expanding the training data (potentially incorporating singing videos for broader vocal coverage), and optimizing the inference backend with TensorRT/ONNX support for further latency reduction and deployment efficiency.

Key Features

💬

Accurate Lip Sync

Phoneme-level alignment between speech audio and lip motion, supporting both speech and singing.

👀

Controllable Gaze & Expression

Independent control over gaze direction and facial expressions for natural, expressive output.

🪮

Identity Preservation

Maintains the subject's appearance and fine facial details across all generated frames.

⏱

250 ms Pose Window

Reduced pose prediction window of just 250 ms enables true real-time streaming with minimal latency — a key advantage over Ditto.

⚡

Real-Time Streaming

End-to-end pipeline designed for live interactive applications, with ongoing TensorRT optimization for deployment efficiency.

🆕

Singing Support

Generalizes beyond speech to singing synthesis, with training data expansion planned for broader vocal coverage.
